# Image embeddings and semantic search

## Start the services

Start PostgreSQL and the multimodal embedding API/worker. The latter listens on `127.0.0.1:8091` by default.

```sh
docker compose up -d db
docker compose -f docker-compose.embeddings.yml up --build -d
```

Keep the embedding service bound to localhost unless you have added suitable authentication and network controls. Set `EMBEDDING_SERVICE_URL` if the API is running elsewhere.

## Build embeddings

`npm run assets:embed` retains the existing metadata-text embedding step through Ollama and additionally computes image embeddings through the CLIP service. Set `IMAGE_EMBEDDINGS=false` to disable the image path. Text model names can be passed after `--` or configured with `EMBEDDING_MODELS`.

Only assets with a verified/uploaded file status, a local path, and a matching SHA-256 are embedded as images. Run reconciliation and upload first, and ensure local originals are still present. The image vector is stored in `asset_embeddings` with modality `image`, its actual dimensions, the source file SHA-256, and a digest identifying the configured image/text model pair. This prevents a query from accidentally comparing vectors generated by an incompatible pair.

Jobs are submitted to the embedding service's durable queue and polled until complete, failed, or timed out. Tune `EMBEDDING_JOB_TIMEOUT_MS` (default 300000) and `EMBEDDING_JOB_POLL_MS` (default 750) if needed. The command reports failures per asset rather than stopping the whole batch.

## Search

```sh
npm run assets:search -- 'Jeesus siunaa lapsia' 10
npm run assets:search -- 'risti ja tyhjä hauta' 10 oma-kirjasto
```

Arguments are the Finnish text query, optional result limit (1–100, default 10), and optional library slug. The text query is embedded using the CLIP text encoder; PostgreSQL/pgvector ranks stored image vectors by cosine similarity. Results include asset metadata and similarity scores. Search requires image vectors for the same configured model pair and vector dimension; it does not silently fall back to unrelated Ollama text vectors.

## Current boundaries

- Search is currently a CLI command, not an HTTP API or web UI.
- Query vectors are transient and are not persisted.
- Retrieval quality has not yet been evaluated on a representative, human-labelled Finnish church-image set.
- Model pair identity is recorded, but immutable upstream model revisions still need to be pinned before treating the index as reproducible across deployments.
